# Fish Beat Kitchen

Self-contained rhythm game build. Open `index.html` directly in a browser; all artwork and audio are embedded as data URIs, so no extra files are required.

- `index.html` — standalone build (works from `file://` or any static host)
- `index.source.html` — source build with relative `assets/` references
- `assets/` — original image and audio files used by the source build

Controls: Arrow Left / A for salmon, Arrow Right / D for squid. Clicking the left or right half of the game area also works.
