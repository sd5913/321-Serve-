# Menu theme

`rolling-rhythm.mp3` is the original user-supplied **Rolling Rhythm-3.mp3**, copied without re-encoding.

It loops on the home screen and level selector, pauses on entry to any level (including tutorial/count-in and empty level placeholders), and resumes at its saved position when returning to the menu. It also pauses while the page is hidden. The existing level music and chart are separate and unchanged.

The Music slider and SOUND toggle apply to this track. Its menu gain is 0.45. The page attempts audible playback when opened; browsers that block autoplay will start it on the first eligible pointer or keyboard interaction. No extra prompt is shown.

Active menu track updated to Rolling Rhythm-3; its original MP3 bytes are preserved, and the media URL is versioned so browsers fetch the replacement.
