# Start-page rhythm layers

Approved fixed-clock-hands animation: 120 BPM, four beats / two-second loop. The three sushi characters bounce in sequence and respond together on the fourth beat; the accent pulses. Clock hands remain static.

The page uses `startpage-motion.js` to draw the separate PNG layers at screen pixel density (up to 3x), rather than enlarging the indexed-color GIF. `preview.gif` is the approved motion reference only. `motion-lines.png` is retained as a separate optional layer; it is not animated in the approved preview.

The clean background contains only the left part of the preview. Existing HTML logo and buttons remain independently rendered and interactive. Original UI reference images are preserved. Layers were extracted/reconstructed with AI assistance for this approved preview; their native dimensions are retained.

Animation runs only while the start screen is visible. OS reduced-motion preference and the game's Reduced Motion checkbox show a static composition. Gameplay, tutorial, soundtrack and chart are independent of this decorative animation.
