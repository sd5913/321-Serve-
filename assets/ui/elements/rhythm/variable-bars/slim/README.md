# Slim rhythm bars / 细框版节奏条

## English

This folder contains slim rhythm bars with 1–6 dots. The tutorial HUD uses the appropriate slim slot count for each lesson. The main level keeps four judgments on screen and advances only when all four slots have been judged. Original assets are preserved for comparison.

- Each variant includes a transparent PNG and an editable SVG.
- Dot diameter and spacing match the earlier variable-bar previews.
- The navy capsule is shorter with less padding at both ends.
- Colors: navy `#00133A`, cream `#FCEBD1`.
- Normal 1–5-dot variants: [Parent folder](../).
- Existing six-dot states: [six-beat-states](../../six-beat-states/).

## 中文

此目录包含 1–6 点细框版素材。当前教学 HUD 按每组操作数使用 slim 样式，正式关卡使用四点一组的 slim 样式；四个点全部判定后才切换下一组。原版素材保留，方便对比。

- 每款均有透明 PNG 和可编辑 SVG。
- 圆点直径与点间距沿用上一套预览。
- 深蓝底条更矮、两端留白更小。
- 颜色：深蓝 `#00133A`、米白 `#FCEBD1`。
- 普通版 1–5 点：[上级目录](../)。
- 既有 6 点状态图：[six-beat-states](../../six-beat-states/)。
