# Variable-dot rhythm bars / 可变点数节奏条

## English

- Normal: `bar-1-pending` through `bar-5-pending`, supplied as transparent PNGs and editable SVGs. Existing six-dot assets remain in [six-beat-states](../six-beat-states/).
- [Slim](slim/): one to six dots, each supplied as a transparent PNG and an editable SVG.
- Normal geometry: dot diameter 60, gap 36, horizontal padding 48 and height 120.
- Slim geometry: dot diameter and gap are unchanged; horizontal padding 24 and height 92.

The tutorial HUD uses slim bars with 2, 4, 2 and 1 slots. The main level uses four-slot slim pages. Each result stays in its slot until all four inputs have been judged; only then does the next page appear. Unused slots on the final page are dimmed. Normal assets are preserved for comparison.

## 中文

- 普通版：`bar-1-pending` 至 `bar-5-pending`，透明 PNG 与可编辑 SVG。既有六点素材保留在 [six-beat-states](../six-beat-states/)。
- [细框版](slim/)：1–6 点，每款均有透明 PNG 与可编辑 SVG。
- 普通版几何：圆点直径 60、间距 36、端部留白 48、高度 120。
- 细框版几何：圆点与间距不变，端部留白 24、高度 92。

教学 HUD 按当前组显示 slim 版 2、4、2、1 点；正式关卡使用 4 点 slim 分组。每个点保留命中或漏拍结果，整组四个操作均判定后才切换下一组；末组不足四次的空位淡化。普通版素材继续保留供对比。
