# Level 2 — Fish game assets / 第二关鱼类游戏素材

## English

Each PNG is an individual high-resolution asset with its alpha channel and transparent margins preserved. The files were not enlarged from an overview screenshot.

- cutting-board: four cutting-board variants.
- fish-*: old and new fish poses, expressions, lengths and single-eye position alternatives; filenames distinguish versions.
- hand-*: reaching-out and downward-grabbing poses, with four alternatives for each.
- net-*: reaching-out/downward-sweeping nets, long- and short-handled nets, and large nets holding three fish, with four alternatives for each; the mesh openings are transparent.
- tv-frame: a separate transparent television frame with a transparent screen opening.
- tv-screen-background-*: separate screen-content backgrounds; the screen area is colored, while the surrounding area and the area outside the rounded corners are transparent.
- tv-with-abstract-screen: a combined television preview that can be used directly.

The latest design does not include a cabinet or a complete scene containing a cabinet. Only artwork assets were added; no game code was modified.
manifest.json records the high-resolution sources, crop regions, output dimensions and SHA-256 hashes.

## 中文

每个 PNG 是一个独立高清素材，保留透明通道与透明边距；未使用总览截图放大。

- cutting-board：4 种案板。
- fish-*：新旧鱼姿态、表情、长度与单眼位置候选，文件名区分版本。
- hand-*：伸出与向下抓取，各 4 个候选。
- net-*：伸出/下扫、长短柄、三鱼大网，各 4 个候选；网孔透明。
- tv-frame：独立透明电视边框，屏幕开口透明。
- tv-screen-background-*：独立屏幕内容底图；屏幕内有颜色，四周和圆角外透明。
- tv-with-abstract-screen：电视组合预览，可直接使用。

按最新方案不包含柜子或带柜子的整张场景。只新增美术资产，不修改游戏代码。
manifest.json 记录高清来源、裁切区域、输出尺寸和 SHA-256。
