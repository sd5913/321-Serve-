# Level 4 — grilling assets

66 individual RGBA PNG assets selected from the supplied level-4 montage. Original source resolution is retained; files are not artificially enlarged. Each sprite has transparent padding of 12 px. Near-transparent edge noise is removed.

- `level4-flame-01..03`: flame alternatives.
- `level4-blowtorch-01..03`: shortened side-view blowtorches.
- `level4-salmon-small-v1..v3-{front,left,back,right}`: small salmon alternatives.
- `level4-{salmon,squid}-{raw,cooked,charred}-{front,left,back,right}`: faceless food states, with a rear cleft marker. Cooked sprites include oil highlights.
- `level4-face-happy-01..09`: happy overlays.
- `level4-face-frightened-01..04`: simple frightened overlays with brows, as selected in the montage.
- `level4-face-shocked-01..04`: white-eyed shocked overlays without brows.
- `level4-face-gasp-01..04`: small-pupil white-eyed gasp overlays without brows.
- `level4-smoke`, `level4-swear-symbols`, `level4-grill`: feedback effects and supplied high-resolution grill.

See `manifest.json` for pixel dimensions and source references. Filenames identify orientation relative to the character. Keep original aspect ratios when rendering. Expressions are independent overlays, not baked into the large food sprites.
