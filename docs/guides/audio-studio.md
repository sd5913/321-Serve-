# 调音台指南

打开游戏页面底部的 **调音台 ♫**。主时间线以 140 BPM 显示节拍，内置音效、导入音频和组合音效会显示波形。

| 要做什么 | 操作 |
| --- | --- |
| 替换音源 | 把文件拖到轨道，或点轨道上的「换」。可一次拖入多个文件，作为独立音效添加 |
| 定位、预览 | 拖时间尺或播放头定位，按空格播放或暂停。缩放范围为 50%–400%；可按 1/4 拍、1/3 拍吸附 |
| 裁剪、移动 | 拖两端裁剪，拖中间移动。左右方向键微移 0.001 拍，按住 Shift 微移 0.01 拍；按住 Alt／Option 拖动可取消吸附。也可输入数值 |
| 编辑组合 | 双击片段或点「层」打开子草稿。可移动、裁剪原声和子音效，并设置子音效音量 |
| 删除、撤销 | 选中片段按 Delete 或 Backspace；轨道上的 × 删除整轨。可用撤销、重做恢复近期改动 |
| 保存、备份 | 「保存」或 ⌘／Ctrl + S 保存到当前浏览器。「新草稿」从上次保存版开始。换设备前可导出工程 JSON，再导入并保存 |

裁剪会保留原始音频。共用同一音源的重复片段共享裁剪范围。组合波形由音轨实际混音生成。

## 按节奏校对

- **●** 是固定时间播放的音效。改动后在关卡里试听弹出或反弹是否对齐画面。
- **◆** 是按键响应声。调音台预览会模拟触发；正式关卡即时播放玩家实际按下的动作声。游戏的操作时间由谱面决定。
- 原始录音和运行用短音效应可以追溯。[饭团音频目录](../../assets/audio/rice-20261124/)里的 [segments.json](../../assets/audio/rice-20261124/interactive/segments.json) 记录切分位置。替换三连时，至少试听一次从三颗饭团弹出到最后拍走的完整示范。
- 教学中同一项的示范、练习和重试共用循环背景音乐；切到下一项时从头播放。若听见伴奏重叠，先单独试听导入的动作音源。
