# 试玩指南

下载或克隆仓库，在浏览器打开本地 [index.html](../../index.html)。保持素材和脚本的目录结构。手机可横屏试玩。

选择 **Rice Rice Baby**，点击 **START → GOT IT**。四项教学各有示范和练习，通过后进入正式关卡。

| 看见什么 | 怎么按 |
| --- | --- |
| 普通出饭 | **A** 捏成形，再按 **D** 扫走 |
| 故障反弹 | 等它反弹落定，按 **A → D** |
| 连出三份 | 从右到左按 **A → A → A → D**，最后扫走整批 |
| 海绵 | 直接按 **D**。误按 **A** 会挤出水花并记为错误 |

触屏的左半区对应 A，右半区对应 D。提示圆环收拢时出手。正式关卡约 77 秒，共 44 组、90 个操作点。

按 **Esc** 或画面内暂停按钮暂停，从暂停菜单继续。设置里可分别调整音乐和音效音量，也可以用 **Input Offset** 校正判定。若动作总被判偏晚，可在设置中尝试小幅增加补偿值，并用同一句节奏重新验证。

反馈时请记下关卡、出现问题的动作、浏览器和设备。[试玩记录](../playtest-log.md)
