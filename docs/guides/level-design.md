# 关卡设计指南

## 先让厨房动作表达节奏

玩家需要从食材、声音与动作看懂「要按什么」和「什么时候按」。以 **机器蓄力 → 食材落位 → 玩家输入 → 动作反馈** 为骨架。普通段先建立一次捏、一次扫的基本节奏，再用反弹改变等待时间、用三连练同键连按、用海绵打破 A → D 的习惯。

| 现有关卡 | 关卡或素材状态 |
| --- | --- |
| Rice Rice Baby | 可玩。正常出饭、三连、故障反弹与海绵构成四项教学和正式谱面 |
| Catch Me If You Can | 选关入口 |
| Sashimi, Baby! | 选关入口与鱼料、砧板、筷子等美术。[素材说明](../../assets/level3/README.md) |
| Grill Me Maybe | 选关入口与烤架、食材熟度、火焰等美术。[素材说明](../../assets/level4/README.md) |

## 从参考音频到谱面

1. 给每组动作保留完整参考音频。标出机器开始、弹出、落稳、反弹、操作和收尾的时间点。
2. 分开记录组的起始秒数和组内动作时间。饭团关卡前者在 [timing.json](../../assets/audio/rice-20261124/timing.json) 和运行用谱面中，后者定义在 [game.js](../../game.js) 的 `phraseSeconds`。调音台的 140 BPM 网格便于编辑，录音中的实际间隔以秒数为准。
3. 用同一组动作点对齐示范、判定和提示。三连的四个操作点是组内约 1.84、2.27、2.74、3.19 秒。调整扫走的位置时，一起试听第三捏到扫走的间隔。
4. 先用一组动作验证，再放进整条关卡。分别试准拍、提前、漏拍和误按，并从示范玩到正式关卡。

## 画面和声音各司其职

- 保留项目的粗描边、米白和深蓝视觉语言。机器、食材、手和反馈尽量用同一视角，分层导出以便调整动作。[美术素材](../../assets/README.md)
- 用红灯、抖动和短音预告故障。飞行与反弹用快慢变化和形变表现，落稳位置要能看清。
- 练习和正式关卡中，捏、扫、挤海绵的音效跟随实际输入。漏拍时可以反馈判定，避免提前播放一个玩家还没触发的动作声。
- 背景音乐和动作素材分轨。导入新录音后试听整句，检查是否把伴奏带进了自动提示或按键音轨。

后续关卡的玩法草案与素材清单可从[文档目录](../README.md)进入。
